## Goal
- 가족 한 명이 30초 안에 가족을 만들고, 다른 구성원이 코드 한 번 입력으로 가입해서 즉시 함께 진진거를 시작할 수 있다.

## In scope
- 가족 생성: 가족 이름 + 6자리 영숫자 코드 자동 발급(또는 사용자 의도로 재발급).
- 가족 코드로 가입: 코드 입력 → 가족 미리보기 → 가입 확정.
- 가족 멤버 목록(닉네임, 가입일).
- 가족 코드 다시 보기 / 코드 공유(딥링크).
- 가족 정원 8명.
- 1인 1가족 제한(MVP).

## Out of scope
- 가족 변경(탈퇴 후 재가입 외).
- 가족 삭제, 멤버 강퇴, 권한 위임.
- 다중 가족 가입.
- 가족 프로필(소개글, 이모지, 컬러 테마 — v1.1 후보).

## User story
- As a 가족의 첫 번째 사용자
- I want 가족을 만들고 코드를 빠르게 공유하고 싶다
- so that 다른 가족이 5분 안에 진진거에 합류할 수 있다.

## Definitions
- **가족 코드**: 영문 대문자(`A`~`Z` 중 `I`, `O` 제외) + 숫자(`2`~`9`) 조합 6자리. 예: `H7K2QN`.
  - 헷갈리는 문자 제외(I/L/1, O/0).
  - 코드 공간 = 24문자 + 8숫자 = 32자, 32^6 ≈ 10억 조합. 충돌 시 자동 재시도.
- **가족 이름**: 사용자 입력. 1~20자. 한국어/영문/숫자/이모지 허용.
- **소유자(Owner)**: 가족을 처음 만든 사용자. MVP에서는 권한 차이 없음(향후 권한 분리 가능성).
- **가족 정원**: 한 가족의 최대 멤버 수 = 8명.

## Scenarios

```gherkin
Feature: 가족 만들기

  Scenario: S-1 인증된 사용자가 가족을 만든다
    Given 사용자가 로그인했고 어떤 가족에도 속해 있지 않다
    When 사용자가 `/onboarding`에서 "가족 만들기" 탭을 선택하고 가족 이름 "콩가족"을 입력한 뒤 "만들기"를 누른다
    Then 시스템은 새 `Family`를 생성한다
    And `Family.code`는 6자리 영숫자(허용 문자셋)로 자동 생성된다
    And 시스템은 이 사용자를 owner로 `FamilyMember`로 추가한다
    And 사용자를 `/home`으로 이동시키고 화면 상단에 가족 코드를 노출한다

  Scenario: S-2 가족 이름 자동 추천
    Given 사용자가 가족 이름 입력란을 비워 두었다
    When 사용자가 "재밌는 이름 추천" 버튼을 누른다
    Then 시스템은 한국어 가족 이름 후보 5개를 표시한다 (예: "콩가족", "리모컨 탐정단", "주말 야식 클럽")
    And 사용자가 후보 1개를 누르면 입력란에 채워진다
    And 사용자는 채운 뒤 자유롭게 수정할 수 있다

  Scenario: S-3 가족 이름이 비어 있거나 너무 길다
    Given 사용자가 가족 이름 입력란을 비워 두었거나 21자 이상을 입력했다
    When 사용자가 "만들기"를 누른다
    Then 시스템은 가족을 생성하지 않는다
    And 입력란 아래 "가족 이름은 1~20자여야 해요"를 표시한다

  Scenario: S-4 코드 충돌 시 자동 재생성
    Given 시스템이 발급한 6자리 코드가 기존 활성 가족과 충돌한다
    When 시스템이 가족 생성 트랜잭션을 처리한다
    Then 시스템은 같은 트랜잭션 안에서 코드를 최대 5회까지 재시도한다
    And 5회 모두 실패한 경우에만 사용자에게 "잠시 후 다시 시도" 메시지를 노출한다

Feature: 가족 가입

  Scenario: S-5 코드로 가족 미리보기 후 가입한다
    Given 사용자가 로그인했고 어떤 가족에도 속해 있지 않다
    When 사용자가 `/onboarding`에서 "가족 가입" 탭을 선택하고 코드 "H7K2QN"을 입력하고 "찾기"를 누른다
    Then 시스템은 가족 이름과 현재 멤버 수를 미리보기로 표시한다 (예: "콩가족 · 멤버 3명")
    When 사용자가 "이 가족에 가입"을 누른다
    Then 시스템은 사용자를 `FamilyMember`로 추가한다
    And 사용자를 `/home`으로 이동시키고 환영 토스트를 표시한다

  Scenario: S-6 존재하지 않는 코드
    Given 사용자가 가족 가입 화면에 있다
    When 사용자가 코드 "ZZZZZZ"를 입력하고 "찾기"를 누른다
    And 해당 코드의 활성 가족이 없다
    Then 시스템은 "이 코드의 가족을 찾을 수 없어요"를 표시한다
    And 미리보기는 표시하지 않는다

  Scenario: S-7 코드 형식이 잘못됐다
    Given 사용자가 가족 가입 화면에 있다
    When 사용자가 5자리 또는 7자리 또는 허용되지 않은 문자(I, O, 0, 1)를 포함한 값을 입력했다
    Then 시스템은 "찾기" 버튼을 비활성화한다
    And 입력란 아래 "코드는 6자리 영문 대문자와 숫자(I, O, 0, 1 제외)예요"를 표시한다

  Scenario: S-8 가족 정원 초과
    Given 가족 "콩가족"의 활성 멤버가 8명이다
    When 9번째 사용자가 코드 "H7K2QN"으로 가입을 시도한다
    Then 시스템은 가입을 거부한다
    And "이 가족은 정원(8명)이 가득 찼어요"를 표시한다

  Scenario: S-9 이미 가족에 속한 사용자가 다른 가족 가입 시도
    Given 사용자는 이미 어떤 가족의 멤버이다
    When 사용자가 다른 가족 코드를 입력하고 가입을 시도한다
    Then 시스템은 가입을 거부한다
    And "한 사용자는 한 가족에만 속할 수 있어요. 먼저 현재 가족에서 나가야 해요"를 표시한다
    And "현재 가족 보기" 링크를 함께 노출한다

  Scenario: S-10 같은 가족에 동일 사용자 중복 가입 시도
    Given 사용자는 가족 "콩가족"의 멤버이다
    When 사용자가 같은 코드 "H7K2QN"을 다시 입력해 가입을 시도한다
    Then 시스템은 신규 멤버를 만들지 않고 곧바로 `/home`으로 이동시킨다

Feature: 가족 코드 공유

  Scenario: S-11 가족 코드 다시 보기와 복사
    Given 사용자가 `/me`에 있고 가족의 멤버이다
    When 사용자가 "가족 코드 보기"를 누른다
    Then 시스템은 가족 이름과 6자리 코드를 노출한다
    And "코드 복사" 버튼을 누르면 클립보드에 코드만 복사된다
    And "초대 메시지 복사" 버튼을 누르면 "[가족이름]에서 진진거 같이 해요. 코드: [코드] · 진진거 다운로드: [URL]" 형식의 메시지가 클립보드에 복사된다

  Scenario: S-12 딥링크로 코드 자동 채움
    Given 가족 단톡방에서 "https://진진거/join?code=H7K2QN" 링크를 받았다
    When 사용자가 링크를 눌러 진입한다
    And 사용자가 로그인 후 `/onboarding`에 도달했다
    Then "가족 가입" 탭이 자동 선택돼 있다
    And 코드 입력란에 "H7K2QN"이 자동으로 채워져 있다
    And 가족 미리보기가 자동으로 표시된다

Feature: 가족 멤버

  Scenario: S-13 가족 멤버 목록과 닉네임
    Given 사용자가 `/family`에 있다
    Then 시스템은 가족 멤버 목록을 가입 순으로 표시한다
    And 각 멤버는 표시 이름(또는 본인이 설정한 닉네임)과 가입일을 보여준다
    When 사용자가 자신의 항목 옆 "닉네임 변경"을 누른다
    Then 사용자는 가족 안에서만 사용될 닉네임(1~12자)을 입력해 저장할 수 있다
    And 다른 가족에는 영향이 없다
```

## Acceptance criteria
- 모든 시나리오는 E2E 또는 통합 테스트로 검증 가능.
- 가족 코드 정규식: `^[A-HJ-NP-Z2-9]{6}$`.
- 가족 정원 제한은 트랜잭션 안에서 SELECT … FOR UPDATE 또는 동등한 동시성 제어로 보장한다(8번째와 9번째가 동시에 들어와도 9번째는 거부).
- 닉네임은 가족 단위로 유일성 강제하지 않음(엄마가 둘이어도 OK).

## Failure modes and recovery
- **코드 brute force 시도**: 가족 가입 미리보기 API에 IP/세션 단위 rate limit 적용(분당 30회).
- **딥링크 코드가 공백/오타**: 자동 채움하되 미리보기에서 정상적으로 "찾을 수 없음" 안내.
- **owner 탈퇴(MVP에서는 미지원)**: 정책 정해질 때까지 owner 본인이 가족을 떠나는 동선 자체를 비활성.

## Open questions
- OQ-F1: 가족 코드 만료(예: 7일) 정책 도입 여부. 보안 ↑, 편의 ↓.
- OQ-F2: owner가 별도 권한을 가져야 하는가(예: 멤버 강퇴, 가족 삭제).
- OQ-F3: 가족 이름 자동 추천을 LLM으로 할지 정적 사전으로 할지(비용 vs 다양성).
- OQ-F4: 가족 코드 재발급 기능 필요성. 발급 후 외부 유출 시 대응.
