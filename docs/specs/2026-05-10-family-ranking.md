## Goal
- 진진거 결과를 단순 정답률 1차원이 아닌 5종의 부드럽고 다양한 랭킹으로 표현해 가족 누구도 일방적으로 비참해지지 않으면서 매주 새로운 재미를 만든다. 더불어 가족이 결과 화면과 대시보드에서 자유롭게 코멘트를 주고받을 수 있는 기본 댓글을 제공한다.

## In scope
- 5종의 가족 랭킹 정의·산식·표시.
- 주간 리셋(매주 월요일 KST 00:00).
- 결과 공개 시점에 점수 가산.
- 댓글: 진진거 결과 화면에 가족 멤버가 자유 텍스트 댓글을 남기는 기능.
- "리액션 장인", "질문왕" 산정에 사용되는 댓글 분류.

## Out of scope
- 가족 간 비교 랭킹/리그(MVP 범위 밖).
- 영구 누적 명예의 전당(MVP 범위 밖, v1.1 후보).
- 댓글에 이모지 리액션, 답글 트리, 멘션, 첨부파일.
- 알림.

## Definitions
- **랭킹 주(Week)**: KST 기준 월요일 00:00 ~ 다음 월요일 00:00. 주의 ID = 그 주 월요일의 `YYYY-MM-DD`.
- **점수(Score)**: 각 랭킹 카테고리별로 산정되는 정수.
- **참여 멤버(Eligible member)**: 그 주에 가족에 속해 있는 멤버 모두. 가입 일자 이전의 진진거는 점수 산정에 포함하지 않는다.
- **댓글 분류(Comment category)**: 댓글 텍스트를 분석해 분류하는 메타데이터. {`reaction`, `question`, `other`} 중 하나. MVP는 간단한 휴리스틱(끝 어미 + 키워드)으로 분류한다(LLM 사용 안 함).

## Ranking categories

### 1. 가족 탐정 (Family Detective)
- 정의: 가짜를 가장 잘 맞힌 사람.
- 산식: 그 주 풀이한 진진거 중 정답 비율(정답 수 / 풀이 수). 풀이 수 < 3은 후보 제외.
- 표기 예: "1위 엄마 — 정답률 80% (4/5)"

### 2. 거짓 설계자 (Lie Designer)
- 정의: 본인이 등록한 진진거에서 가족이 가장 많이 속은 사람.
- 산식: 그 주 등록한 진진거의 평균 속임률. 등록 수 < 2는 후보 제외.
- 표기 예: "1위 동생 — 평균 속임률 72%"

### 3. 순수한 마음상 (Pure-Hearted Award)
- 정의: 가장 자주 속은 사람. 명칭은 부드럽게.
- 산식: 그 주 풀이한 진진거 중 오답 비율. 풀이 수 < 3은 후보 제외.
- 표기 예: "이번 주 순수한 마음상 — 아빠 (오답률 60%)"

### 4. 리액션 장인 (Reaction Star)
- 정의: 가장 활발하게 결과 화면에 반응한 사람.
- 산식: 그 주 작성한 댓글 중 분류가 `reaction`인 댓글 개수.
- 표기 예: "1위 엄마 — 리액션 12개"

### 5. 질문왕 (Question Master)
- 정의: 결과 공개 후 좋은 질문을 가장 많이 남긴 사람.
- 산식: 그 주 작성한 댓글 중 분류가 `question`인 댓글 개수.
- 표기 예: "1위 아빠 — 질문 8개"

## Requirements (EARS)

### 점수 갱신

- **R-1 (Event-driven)**: 진진거 status가 `revealed`로 전환될 때, 시스템은 해당 진진거를 점수 산정에 포함한다.
  - "가족 탐정"·"순수한 마음상"은 풀이 1건당 풀이자에게 가산.
  - "거짓 설계자"는 진진거 1건당 출제자에게 가산.

- **R-2 (Event-driven)**: 댓글이 작성될 때, 시스템은 댓글 분류를 산정해 `Comment.category`에 저장하고 작성자의 점수(R-3)를 갱신한다.

- **R-3 (Ubiquitous)**: 시스템은 다음 카테고리별 랭킹을 그 주 단위로 집계한다.
  - Detective, Lie Designer, Pure-Hearted, Reaction Star, Question Master.

### 주간 리셋

- **R-4 (Event-driven)**: KST 기준 매주 월요일 00:00에 시스템은 새 랭킹 주를 시작한다.
  - 진행 중이던 주는 archive된 상태로 보관되며 대시보드의 "지난 주 랭킹"에서 조회 가능하다.
  - 신규 주의 점수는 0부터 시작한다.

- **R-5 (Ubiquitous)**: 주간 리셋이 발생해도 진진거/댓글 데이터는 삭제하지 않는다. 누적 통계는 별도 집계로 보존된다(F8 dashboard).

### 후보 자격

- **R-6 (Ubiquitous)**: 한 주에 카테고리별 최소 표본 미달인 멤버는 그 주 해당 카테고리에 노출되지 않는다.
  - Detective / Pure-Hearted: 풀이 수 ≥ 3.
  - Lie Designer: 등록 수 ≥ 2.
  - Reaction / Question: 댓글 수 ≥ 1.

- **R-7 (Ubiquitous)**: 자격 미달 카테고리는 "이번 주는 아직 활동이 적어요"로 표시한다.

### 표시

- **R-8 (Ubiquitous)**: 시스템은 5종 랭킹을 카드 5장으로 가족 대시보드(F8) 상단 캐러셀에 표시한다.
- **R-9 (State-driven)**: 동점이 발생한 동안에는 동순위로 함께 표시한다(예: "1위 엄마, 동생").

### 댓글

- **R-10 (Ubiquitous)**: 진진거가 status `revealed`인 동안 가족 멤버는 결과 화면(F5 §결과 공개 화면)에서 댓글을 작성할 수 있다.
- **R-11 (Event-driven)**: 사용자가 댓글을 제출할 때, 시스템은 텍스트를 1~200자로 검증하고 분류기로 카테고리를 결정한 후 `Comment(kind=user, category=…)`로 저장한다.
- **R-12 (Ubiquitous)**: AI 자동 코멘트(F5 S-10)와 사용자 댓글은 동일 화면에서 시간순으로 표시된다.
- **R-13 (Ubiquitous)**: 작성자는 자신의 댓글을 작성 후 5분 이내에만 삭제할 수 있다(MVP, 스팸/오타 대응).
- **R-14 (Unwanted)**: 만약 댓글 텍스트가 차단 패턴(욕설/비방/식별 정보)에 매치되면, 시스템은 저장 전에 거부하고 사유를 표시한다.

### 댓글 분류 휴리스틱 (MVP)

- **R-15 (Ubiquitous)**: 시스템은 다음 규칙으로 댓글 카테고리를 결정한다(휴리스틱, LLM 사용 안 함).
  - 텍스트가 `?` 또는 한국어 의문 어미(`-니`, `-니까`, `-나`, `-가요`, `-까요`, `-요?`)를 포함하면 → `question`.
  - 텍스트가 의문이 아니고 길이 ≤ 30자이며 감탄/리액션 키워드(`ㅋㅋ`, `ㅎㅎ`, `대박`, `진짜?`, `헐`, `미쳤다`, 이모지 1개 이상)를 포함하면 → `reaction`.
  - 그 외 → `other`.

- **R-16 (Optional feature)**: v1.1에서 LLM 분류로 교체 가능하도록 `Comment.categorySource = heuristic|llm`으로 기록한다.

### 가시성

- **R-17 (Ubiquitous)**: 모든 랭킹은 가족 내부에서만 보인다. 다른 가족이나 비로그인 사용자에게는 노출되지 않는다.

## Acceptance criteria

| ID | 검증 |
|----|------|
| R-1, R-3 | 진진거 reveal 시뮬레이션 후 5종 랭킹 점수 변화 통합 테스트. |
| R-2 | 댓글 작성 시점에 랭킹 점수 변화 통합 테스트. |
| R-4 | 시간 모킹으로 월요일 00:00 KST 직전/직후 동작 검증. |
| R-5 | 데이터 보존 검증. |
| R-6, R-7 | 풀이 수 < 3, 등록 수 < 2, 댓글 수 = 0 케이스 단위 테스트. |
| R-9 | 동점 표시 컴포넌트 테스트. |
| R-11, R-14 | 댓글 입력 검증·차단 통합 테스트. |
| R-13 | 5분 경과 후 삭제 거부 검증. |
| R-15 | 휴리스틱 분류기 단위 테스트(질문/리액션/기타 각 5케이스). |
| R-17 | 다른 가족 사용자가 API에 접근 시 403. |

## Failure modes and recovery

| 실패 | 응답 | 사용자 영향 |
|------|------|-------------|
| 점수 산정 작업 실패 | 백오프 재시도, 최대 5회 | 결과 화면 표시는 정상, 랭킹은 다음 갱신 시 일관 |
| 주간 리셋 작업 누락 | 다음 부트 시 catch-up 작업 | 대시보드 첫 진입이 잠깐 느려질 수 있음 |
| 댓글 차단 오탐 | 사용자가 다시 시도 가능 | "다른 표현으로 적어보세요" 안내 |

## Open questions
- OQ-R1: "거짓 설계자" 산정에 백로그 진진거를 포함시킬지(아침에 어제치를 등록하면 가족 풀이 시간이 짧아 속임률이 높게 나올 수 있다).
- OQ-R2: 가족 첫 주는 표본이 거의 없다. "이번 주의 첫 진진거"같은 보조 라벨을 줄지.
- OQ-R3: "리액션 장인" 키워드 사전을 가족별로 학습할지(우리집은 "ㅋㅋ"보다 "ㅠㅠ"가 리액션일 수 있음).
- OQ-R4: 댓글에 이모지 리액션(👍, 😂)을 별도 가산 항목으로 둘지(MVP는 텍스트 댓글만).
- OQ-R5: 주간 리셋 시점에 "지난 주 우리 가족 진진거 베스트" 자동 요약 카드를 띄울지(F8 대시보드 연동).
