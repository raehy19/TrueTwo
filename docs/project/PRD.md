## 1. Executive Summary

진진거는 가족이 매일 한 명씩 자신의 하루를 진짜 2개 + 가짜 1개 형식으로 공유하고, 다른 가족 구성원이 가짜를 추리하는 데일리 게임이다. AI가 그럴듯한 가짜 후보를 제안하고 사람이 마지막에 살을 붙여 등록한다. 가족 내부 풀이·코멘트·랭킹이 1차 핵심 루프이고, 재밌는 진진거를 익명으로 공개하는 "남의 집 진진거" 게시판이 2차 바이럴 루프이다.

성공 시 진진거는 "가족이 거짓을 맞히는 척하면서 서로의 진짜 하루를 발견하게 만드는" 가벼운 데일리 의식이 된다.

## 2. Problem Statement

### 누가 가진 문제인가
- 같이 살거나 떨어져 사는 **2~6인 가족**.
- 부모·자녀·형제·자매가 매일 단톡방에서 "오늘 어땠어"를 묻지만 그 이상으로 가지 못하는 가족.

### 무엇이 문제인가
- 가족은 같이 살아도 서로의 하루를 잘 모른다.
- 사소한 일상은 단톡방에서 공유되기엔 어색하고, 직접 말하기엔 자리가 없다.
- "오늘 뭐 했어?"라는 질문은 정보를 거의 만들지 못한다. 답이 거의 항상 "그냥 똑같지 뭐"이다.

### 왜 아픈가
- 가족 사이의 정서적 거리감이 누적된다. 특히 자녀가 사춘기·성인이 된 뒤로는 부모가 자녀의 일상에 접근할 단서가 거의 없다.
- 부모는 "잔소리한다"는 인식 때문에 묻기를 멈추고, 자녀는 "물어봐도 어차피 모른다"는 이유로 말하지 않는다.
- 결과적으로 가족 안에서 가장 자주 나누는 콘텐츠가 안부 인사 + 음식 사진 + 부고/뉴스 링크에 머문다.

### 증거 (가설)
- 가정의 달 시즌, "가족과 무엇을 할까"에 대한 검색·콘텐츠 소비가 매년 급증한다.
- 단톡방·통화·만남 외에 가족이 함께 사용할 수 있는 디지털 의식(ritual)이 사실상 없다.
- "투 트루스 앤 어 라이"는 영어권에서 30년 이상 검증된 사회적 게임 메커닉이다. 이 메커닉을 가족 일상으로 가져오면, 자연스럽게 "내가 오늘 뭐 했지?"를 떠올리게 만든다.

> 정량 증거는 MVP 출시 후 실제 데이터로 대체한다. 그 전까지는 가설로 둔다.

## 3. Target Users & Personas

### Primary Persona: "엄마 영선 (52)"
- 다 큰 자녀와 같이 살지만, 자녀의 하루는 거의 모른다.
- 단톡방에는 음식 사진과 뉴스만 보낸다. 잔소리로 비치지 않을 핑계가 필요하다.
- 새 앱은 어렵지만, 자녀가 "엄마 이거 같이 해볼래?"라고 시키면 따라 한다.

### Primary Persona: "아들 민수 (27)"
- 회사·자취·가족이 분리돼 있고, 부모와의 대화가 의례적이다.
- 게임/SNS에 익숙하다. "가족과 할 것"에 의무감을 느끼지만 부담은 싫다.
- 가족이 즐거워할 가벼운 콘텐츠가 있으면 매일 하나쯤 등록할 의향이 있다.

### Primary Persona: "동생 지윤 (16)"
- 사춘기. 부모와의 직접 대화는 줄었지만 가족 단톡방에는 가끔 반응한다.
- "재밌으면" 한다. 강제되면 안 한다.

### Jobs-to-be-done
- *When* 가족과 깊은 이야기를 하기 어색할 때, *I want to* 가벼운 게임 형식으로 서로의 하루를 들여다보고 싶다, *so I can* 잔소리 없이 가족과 연결돼 있다는 느낌을 받는다.
- *When* 부모가 자녀 일상에 다가가고 싶을 때, *I want to* 직접 캐묻지 않고 자녀가 자기 입으로 하루를 풀게 만들고 싶다, *so I can* 자녀의 일상에 자연스럽게 참여한다.
- *When* 가족과 멀리 떨어져 살 때, *I want to* 짧고 즐거운 데일리 의식을 공유하고 싶다, *so I can* 매일 가족과 마주치는 디지털 자리를 만든다.

## 4. Strategic Context

### 왜 지금 (Why now)
- 가정의 달(5월) 시즌이 진행 중이다. "가족과 할 것"에 대한 사용자 관심이 가장 높을 때 출시 가능.
- LLM API 비용이 가벼워졌다. AI가 매일 가짜 후보 3개를 만드는 비용이 1인당 1원대.
- 단톡방 대체가 아니라 **단톡방 위에 얹는 가벼운 의식** 포지션이 비어 있다.

### 경쟁 환경
- 카카오 친구 퀴즈, MBTI 챌린지, 인스타그램 "이 중 가짜는?" 스토리.
- 차별점:
  1. **가족 단위 워크스페이스**가 명확히 분리된다.
  2. **AI가 가짜 후보를 만들고 사람이 마지막에 다듬는** 협업형 UX.
  3. **데일리 의식**으로 설계된 등록·풀이·결과 루프.

### 비즈니스 가설
- 한 가족 안에서 진진거가 "매일 보는 화면"이 되면, **B2C 리텐션 게임의 새 카테고리**가 만들어진다.
- 공개 게시판은 신규 가족 유입 채널 역할을 한다("우리도 해볼까").

## 5. Solution Overview

### 핵심 루프

```text
[Step 1] 출제자: 진짜 2개 입력
   ↓
[Step 2] AI: 가짜 후보 3개 제안
   ↓
[Step 3] 출제자: 후보 1개 선택 + 직접 수정 + 난이도 설정
   ↓
[Step 4] 가족: 가짜 추리 + 한 줄 이유 입력
   ↓
[Step 5] 결과 공개: 누가 맞혔는지 + AI 자동 코멘트 + 가족 댓글
   ↓
[Step 6] (옵션) 익명화하여 "남의 집 진진거" 게시판에 공유
   ↓
[Step 7] 주간 랭킹/통계 갱신
```

### 화면 맵 (MVP)
- `/login` 구글 로그인.
- `/onboarding` 가족 만들기 / 가족 가입(코드 입력).
- `/home` 우리 가족 오늘 진진거 + 풀어야 할 진진거 + 결과 보러가기.
- `/quiz/new` 진진거 등록 (3단계 위저드: 진짜 입력 → AI 가짜 → 다듬기/난이도).
- `/quiz/:id/play` 가족 풀이.
- `/quiz/:id/result` 결과 공개 + 코멘트 + 공개 게시판 공유 버튼.
- `/family` 우리 가족 대시보드 (랭킹, 케미 맵, 캐릭터 코멘트).
- `/board` 남의 집 진진거 공개 게시판.
- `/board/:id` 공개 게시판 상세 (정답 보기 + 업보트 + 댓글).
- `/me` 내 통계, 알림, 가족 코드 다시 보기.

### 정보 구조 (요약)
- **User** ←(N:1)— **FamilyMember** —(N:1)→ **Family**
- **Family** —(1:N)→ **Quiz** —(1:N)→ **QuizOption** (진짜 2 + 가짜 1)
- **Quiz** —(1:N)→ **Answer** (가족 구성원의 추리)
- **Quiz** —(1:N)→ **Comment** (AI/사용자)
- **Quiz** —(0:1)→ **PublicPost** (익명화 게시) —(1:N)→ **Upvote**, **Comment**

## 6. Success Metrics

### Primary
- **D7 가족 활성률**: 가족 생성 후 7일 내 가족 단위로 ≥3일 등록 발생한 가족 비율 (목표: 30%+).

### Secondary
- **풀이 참여율**: 등록된 진진거 1건당 가족 N명 중 풀이를 마친 비율 (목표: 70%+).
- **공개 공유 전환율**: 결과 공개된 진진거 중 게시판에 공유된 비율 (목표: 10%+).
- **AI 가짜 채택률**: AI 제안 3개 중 1개를 선택해 등록한 비율 (목표: 70%+).
- **AI 가짜 수정률**: 선택 후 사용자가 수정한 비율 (목표: 50%+, "사람이 살을 붙인다"의 증거).
- **재미 신호**: 결과 화면 평균 댓글 수 ≥ 1.5개/건.

### Guardrail
- **AI 호출 비용**: 활성 가족당 일일 LLM 비용 < 50원.
- **공개 게시판 신고율**: 게시물 1건당 신고 < 0.5%.
- **풀이 폐기율**: 풀이를 시작했지만 미완료한 비율 < 20%.

### 측정 시점
- MVP 릴리스 후 첫 4주.

## 8. UX 원칙

1. **AI는 후보, 사람이 결정**. AI가 제안한 가짜 문장은 항상 사용자 편집 가능 상태로 노출한다. 자동 등록 금지.
2. **5분 안에 첫 가치 도달**. 신규 사용자는 가족 만들기 → 첫 진진거 등록까지 5분 안에 끝난다.
3. **가족이 적어도 즐겁다**. 한 명만 풀어도 결과 화면이 비참하지 않게 설계. 풀이 0명 상태도 의미 있게 표시.
4. **랭킹은 다중 차원**. 단순 정답률만 노출하지 않고, "순수한 마음상", "리액션 장인" 등 부드럽고 다양한 차원으로 분산해 가족 누구도 일방적으로 비참해지지 않게 한다.
5. **공개 공유는 명시적 동의 + 익명화**. 절대 자동 공유하지 않는다. 공유 직전 AI 익명화 미리보기를 반드시 보여준다.
6. **모바일 단톡방 컨텍스트가 진입점**. URL 미리보기, 첫 화면 ATF가 단톡방 화면에서 자연스럽게 보이도록.

## 9. 핵심 비즈니스 규칙 (요약)

> 세부 조건은 각 spec에서 단일 SoT로 정의한다. 본 절은 PRD 차원의 결정 기록이다.

- **B-1 로그인**: 인증은 구글 OAuth만 지원(MVP). 이메일/비밀번호 비지원.
- **B-2 1인 1가족**: MVP에서 한 사용자는 한 가족에만 속한다. 가족 변경은 탈퇴 후 재가입.
- **B-3 가족 코드**: 영문 대문자(I, O 제외) + 숫자(0, 1 제외) 조합 6자리. 충돌 시 자동 재생성.
- **B-4 등록 규칙**: 한 사용자는 하루(서비스 기준 시간대 = Asia/Seoul, 00:00~24:00)에 1개의 진진거만 등록할 수 있다.
- **B-5 즉시 풀이**: 등록 즉시 가족이 풀 수 있다. 등록 시점 = 풀이 시작 시점.
- **B-6 백로그 등록**: 어제(전일) 등록을 안 했다면 오늘 추가로 1개를 더 등록해 전일 진진거를 만들 수 있다. 즉 한 사용자가 같은 날 등록할 수 있는 최대 진진거 수는 2개(오늘 1 + 어제 백로그 1).
- **B-7 풀이 가능 창**: 진진거는 등록 시각으로부터 24시간 동안 풀이가 가능하다. 24시간 경과 시 자동으로 결과가 공개된다.
- **B-8 결과 공개 트리거**: ① 가족 전원이 풀이 완료, ② 출제자가 직접 공개, ③ 등록 후 24시간 경과 — 셋 중 가장 빠른 사건이 발생하면 결과가 공개된다.
- **B-9 출제자 풀이 금지**: 출제자는 자신의 진진거를 풀 수 없다.
- **B-10 공개 게시판**: 결과 공개된 진진거만 출제자 동의 후 공개 가능. 동의 없이 자동 공개 절대 금지.
- **B-11 AI 한도**: AI 가짜 생성 최초 1회 + 리롤 2회 = 가족당 1진진거 최대 3회 LLM 호출. 익명화는 별도로 1회.
- **B-12 가족 정원**: MVP는 가족 1팀 최대 8명.

## 10. 비기능 요구사항 (Non-functional)

- **성능**: 진진거 풀이 화면 LCP < 2.5s on 4G. AI 생성은 첫 토큰 < 3s, 전체 < 8s. 비동기 진행 표시 필수.
- **가용성**: MVP는 99.0%. 단일 region 수용.
- **데이터 보존**: 진진거 본문/풀이/댓글은 영구 보관(가족 자산). 가족 탈퇴 시에는 본인 입력만 익명 처리.
- **개인정보**: 구글 OAuth 최소 정보(이메일, 표시 이름, 프로필 이미지)만 수집. 전화번호/생년월일 비요청.
- **보안**: 가족 코드로 접근 가능한 자원은 가족 멤버 검증을 거친다. 코드 자체에 권한이 있는 게 아니라 "가입 트리거"이며, 가입 후엔 항상 인증된 멤버 ID로 검증한다.
- **접근성**: 모바일 폰트 ≥ 16px, 컬러 대비 WCAG AA. 부모 페르소나가 사용 가능한 글자 크기.
- **로깅**: 모든 LLM 호출은 모델·토큰 수·비용을 1행으로 기록한다(비용 가드레일 메트릭 산출 전제).

## 11. Out of Scope (MVP에서 빼는 것)

- **알림**: 푸시·이메일·카톡 알림 SDK 통합. v1.1로 미룸.
- **첨부파일**: 사진, 동영상, 음성 진진거.
- **다중 가족**: 1인 다가족 가입.
- **결제**: 유료 플랜, 광고.
- **다국어**: 한국어 단일.
- **모더레이션**: 게시판 신고는 단순 수신 폼만 둠. 실제 처리·차단은 v1.1.
- **친구/연인/룸메이트 워크스페이스**: 동일 메커닉이 작동하지만 포지셔닝이 흐려지므로 보류.
- **합산 랭킹/리그**: 가족 간 비교 랭킹은 가족 내부 친밀감을 해칠 위험이 있어 보류.

## 12. Dependencies

### 기술 스택 (확정)
- **프론트엔드**: Next.js (App Router) + TypeScript. UI는 Tailwind + shadcn/ui 기반.
- **호스팅**: Vercel (Edge Network + Serverless Functions). 미리보기/프로덕션 분리.
- **백엔드 / DB / Auth / Storage**: Supabase.
  - Postgres 본체.
  - Supabase Auth(구글 OAuth provider 사용 — F1 spec과 일치).
  - Row Level Security(RLS)로 가족·게시판 권한 강제.
  - Edge Functions 또는 Next.js Route Handlers에서 LLM 호출(서버 보호용 키 보관).
  - Realtime(옵션): 결과 화면 AI 코멘트 도착, 풀이 진행 갱신에 사용 검토.
- **LLM API**: 1개 공급사 단일화로 시작(가짜 생성/익명화/AI 코멘트/캐릭터 코멘트). 비용 가드는 PRD §9 B-11.
- **데이터 모델 단일 SoT**: [`../architecture/data-model.md`](../architecture/data-model.md).

### 외부
- **Google OAuth 2.0**: Supabase Auth provider로 연결. Vercel 환경변수에 클라이언트 ID/Secret 보관.
- **LLM API**: 가짜 생성/익명화/AI 코멘트.

### 내부
- KST 기준 일자 처리 유틸(클라/서버 동일 구현 또는 Postgres `AT TIME ZONE 'Asia/Seoul'` 사용).
- 모든 등록·백로그 규칙은 Asia/Seoul 자정 기준.

### 정책
- **AI 사용 정책 약관**: 출제자가 입력한 진짜 일상이 LLM에 전달된다는 사실, 익명화 옵션을 사용해도 AI에 전달된다는 사실을 가입 단계에서 명시.
- **Supabase 비밀키 정책**: `service_role` 키는 서버 사이드(Next.js Route Handler 또는 Edge Function)에서만 사용. 클라이언트는 `anon` 키 + RLS 정책으로만 접근.

## 13. Risks & Mitigations

| Risk | 영향 | Mitigation |
|------|------|------------|
| 가족 한 명만 등록하고 다른 사람이 안 푼다 | 핵심 루프 붕괴 | "어제 가족 N명이 너의 진진거를 안 풀었어" 푸시(MVP는 이메일 대체) + 풀이 안 한 사람도 정답 공개 후 진입할 동선 제공 |
| AI가 너무 뻔한 가짜를 만든다 | 재미 하락 | 난이도 4단계 + 리롤 2회 + 직접 수정 + 가족 평균 속임률 피드백을 다음 호출 프롬프트에 반영 |
| 가족이 가짜를 너무 잘 맞혀서 출제자가 민망 | 등록 동기 하락 | "출제자 거짓 설계자" 랭킹 + 너무 티 났을 때 부드러운 코멘트("아빠는 형의 패턴을 너무 잘 알아요") |
| 공개 게시판이 자극적 콘텐츠 경쟁이 된다 | 브랜드 손상 | 카테고리 5종(레전드/그럴듯/가족다운/웃긴 오답/따뜻한)을 노출. 업보트 외에 카테고리별 노출. AI 익명화에서 자극 키워드 검출 시 경고 |
| 사춘기 자녀가 가족에 읽히고 싶지 않은 일을 등록 | 신뢰 붕괴 | 등록 시 "이 내용은 가족 전원이 본다" 명시. 게시 후 1시간 내 본인 삭제 가능 |
| AI 비용이 사용량에 따라 폭증 | 비용 가드레일 위반 | B-11 호출 한도 + 캐싱 + 모델 다운그레이드 fallback |
| 단일 가족이 다 안 들어와서 외로움 | 리텐션 저하 | "혼자 게임" 모드(가족이 아직 없을 때 자기 진진거 등록 후 공개 게시판으로 즉시 가는 동선) |

## 16. Glossary

- **진진거**: 진짜 + 진짜 + 거짓의 줄임말. 본 서비스의 콘텐츠 단위.
- **출제자(Author)**: 하루 진진거를 등록한 사용자.
- **풀이자(Solver)**: 가족 중 출제자를 제외한 사용자.
- **가족(Family)**: 진진거의 워크스페이스 단위. 6자리 코드로 식별.
- **백로그 등록(Backlog quiz)**: 어제 등록을 못 한 사용자가 오늘 한 번 더 등록할 수 있도록 허용된 진진거.
- **속임률(Fool rate)**: 한 진진거에서 가짜를 못 맞힌 풀이자의 비율.
- **케미 맵(Chemistry map)**: 가족 구성원 간 정답률을 매트릭스로 표현한 시각화.
