# Status Reports

This directory stores formal status artifacts, not the day-to-day recovery log.

## Use This Directory For
- Milestone summaries
- Handoff reports
- Release-readiness reports
- Explicitly requested status documents

## Do Not Use This Directory For
- Routine session notes
- Daily scratch tracking
- Replacing `docs/operations/current-state.md`

## Archive Rule
- Move older formal reports to `archive/`.
