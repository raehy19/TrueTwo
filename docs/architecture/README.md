# Architecture Guide

This directory is for system-structure records after the product brief is defined.

## What this directory does right now
- It reserves the location for architecture documents.
- It deliberately avoids guessing system structure before product scope is clear.

## Docs to add later
- System context
- Core domain model
- Data flow
- External integration boundaries
- Deployment and operations structure
- Recovery and observability strategy

## ADR Rules
- Record structurally meaningful decisions in `adr/`.
- Include background, options, final decision, consequences, and rollback impact.
- If product intent is still unclear, send the item to the approval queue before creating an ADR.
